# 实际模型验收样例

本机 Codex 实际生成。初始业务数据为示例。

产品问题：人工比较模型回答时，需要统一记录用例、模型、回答和评分，并快速定位失败案例。用户未提供外部资料；本原型的流程与评分文案属于产品设计假设，不代表客观模型能力结论。

范围：单文件 HTML、CSS 和原生 JavaScript，代码不超过 6500 字符，无外部依赖或网络调用。实现新增、编辑、确认删除、搜索、Bad Case 筛选、平均分与 JSON 导出。中文界面适配移动端。

已实现流程：填写标题、模型名称与回答，选择 1—5 分，可勾选 Bad Case 后保存；必填文本拒绝纯空格。编辑会回填表单，可保存或取消；删除需确认。搜索同时匹配标题、模型及回答，并与 Bad Case 筛选组合。统计与导出均基于当前筛选；无匹配显示空态，平均分显示“—”。导出包括零条记录的结果。

数据结构：记录包含 id、title、model、answer、score（1—5 整数）、bad（布尔值）、sample（示例标记）。JSON 导出包含 exportedAt、scope、records。首次打开载入两条明确标注的示例；示例参与统计，编辑后保留示例标记，可删除。

本地数据与持久化：所有新增、编辑、删除、筛选和统计均使用浏览器本地数据。localStorage 可用时保存至当前浏览器；不可用或读写异常时回退内存，并提示刷新后更改会丢失。导出由浏览器生成文件，不上传内容。

验收标准：新增合法记录后数量与平均分立即更新；编辑后数据同步更新；取消删除不改变记录，确认删除后移除；组合搜索与筛选准确影响列表、统计和导出；所有用户输入按文本展示；存储不可用仍能完成当前页面操作；手机上使用单列布局；所有字段具备标签，反馈通过状态区域播报。

限制：这是浏览器原型，非已部署的全栈系统。没有账号、云同步、协作、导入、版本历史或撤销功能。评分为人工主观评分，未提供经验证的评价标准。没有模拟 AI，也没有实际 AI API。未来如需自动获取回答，应增加服务端模型适配、凭证保护、超时与错误处理，并将自动生成内容与人工评价明确区分。此交付未执行浏览器测试；验收条目是验证要求，不是已完成测试的声明。
